## Introduction

There are many great fullstack templates on GitHub; this project draws inspiration from several. Many are heavy (not a bad thing) and less friendly for beginners. This project focuses on a blog domain and offers a complete, lightweight fullstack example (frontend + admin + backend) using modern, popular tech with thorough comments — ideal for learning.

It can also be used to deploy a dynamic blog with one command (see [Quick Start](#quick-start)).

Frontend:

- Design inspired by Hexo's Butterfly — clean and elegant
- Responsive layout, mobile-friendly
- Likes and visitor statistics (Redis)
- Comments + replies
- Bullet-screen style message wall
- Article details include TOC, recommendations, etc.

Admin:

- JWT authentication
- RBAC permissions (Casbin in older versions; now custom RBAC in server)
- Dynamic menus generated by backend (dynamic routes)
- Markdown editor for articles
- Standard admin features: sidebar, breadcrumbs, tags bar, etc.
- Operation logs (non-GET requests)
- Online user monitoring and force logout
- File uploads: Qiniu and local (more planned)
- Common hooks wrapping CRUD

Other:

- RESTful APIs
- Frontend served by Nginx; backend via Docker
- Clean code and structure for easy learning
- Modern stack, lightweight code, reasonable abstractions
- Docker Compose one-click deploy

## Quick Start

Clone the repo and try the one-click run to see it locally.

If you need to modify source code, use the regular run (frontend and backend separately).

This project is developed on Linux. If you encounter issues on Windows, please join the group or open an issue.

### Before cloning (Windows)

On Windows, run the following to avoid Docker build issues.

Alternatively, download the ZIP instead of `git clone`.

Linux/macOS users can skip this.

Reason: The project uses LF line endings (Linux). Windows Git may convert to CRLF, which can break builds.

Note for Docker deployment: update `GetEmailVerifyURL` in `gin-blog-server/internal/utils/email.go` to use your domain instead of `localhost:port`.

```bash
# 防止 git 自动将换行符转换为 crlf
git config --global core.autocrlf false
```

### Option 2: Regular run

Install Golang, Node, MySQL, and Redis:
 
- Golang: [official docs](https://go.dev/doc/install)

- Node: use [nvm](https://nvm.uihtm.com/) or download from [nodejs.org](https://nodejs.org/en)

- MySQL/Redis: recommended via Docker

The following Docker examples are not persisted and are for development/demo only.

MySQL via Docker:

```bash
# 注意: 必须安装 MySQL 8.0 以上版本
docker pull mysql:8.0

# 运行 MySQL
docker run --name mysql8 -e MYSQL_ROOT_PASSWORD=123456 -p 3306:3306 -d mysql:8.0

# 查看是否运行成功, STATUS 为 Up 即成功
docker ps

# 进入容器, CTRL + D 退出
docker exec -it mysql8 bash
mysql -u root -p123456
```

Redis via Docker:

```bash
docker pull redis:7.0

# 运行 Redis
docker run --name redis7 -p 6379:6379 -d redis:7.0

# 查看是否运行成功, STATUS 为 Up 即成功
docker ps

# 进入容器, CTRL + D 退出
docker exec -it redis7 bash
redis-cli
```

Start the backend first, then the frontends, since many frontend configs are loaded from the backend (e.g., menus).

拉取项目到本地：

```bash
git clone https://github.com/szluyu99/gin-vue-blog.git
```

Run backend:

```bash
# 1、进入后端项目根目录 
cd gin-blog-server

# 2、Edit runtime configs (default: config/config.toml)

# 3、Import gvb.sql into MySQL

# 4、Start Redis

# 5、运行项目
go mod tidy
go run main.go
```

Default users in DB:

- Admin: admin / 123456
- User: user / 123456
- Test: test / 123456

Run frontends: This project uses pnpm; install it globally.

```bash
npm install -g pnpm
```

Blog frontend:

```bash
# 1、进入前台前端项目根目录
cd gin-blog-front

# 2、安装依赖
pnpm install

# 3、运行项目
pnpm dev
```

Admin frontend:

```bash
# 1、进入后台前端项目根目录
cd gin-blog-admin

# 2、安装依赖
pnpm install

# 3、运行项目
pnpm dev
```
